# Out-of-scope pictures for the qa_image suite

Pictures the reports do NOT cover (a part, damage or material not in the three NTSB reports - e.g. a cracked
bicycle frame, a corroded pipe). The agent should say the reports don't cover it (`grounded: false` or an explicit
"not covered / not stated"), not invent a diagnosis. Could not be made offline without stock photos, so none yet.

Drop `.jpg` / `.png` files here (your own photos or public-domain ones); the suite adds each as a `test` case.
An optional sidecar `<file>.json` with `{"question": "..."}` adds a user question.
