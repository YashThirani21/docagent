# docagent
Private, fully offline document agent for industrial technical docs. Auto-routes chat input (text, photos, PDFs): extracts every value on engineering drawings to structured JSON, or diagnoses part failures from PDF reports via hybrid RAG. Local Qwen2.5-VL (Ollama/vLLM), bge-m3 + Qdrant, bulk upload, per-request tracing and incremental eval suites.
